
### **WoodenSpeed:**
**Это довольно простой и удобный мод с помощью которого вы сможете срубать деревья целиком!**





> **Этот мод подходит как и для каких либо майнкрафт сборок так и для простой игры потому что не требует сложной настройки!**

Подробнее:

Этот мод создан для быстрой рубки деревьев в майнкрафт, благодоря ему вы можете срубать деревья целиком, сломав основание,

**Быстрая рубка дерева работает только если у вас в руке есть какой либо топор!**

# EN

### **WoodenSpeed:**
**This is a fairly simple and convenient mod that allows you to chop down entire trees!**

<details>
<summary>Video</summary>

</details>



> **This mod is suitable for both various Minecraft modpacks and vanilla gameplay because it doesn't require complex configuration!**

More details:

This mod is created for fast tree chopping in Minecraft, allowing you to cut down whole trees by breaking the base,

Rapid tree-chopping only works if you have an axe of some kind in your hand!~~~~

Current mod version: **1.1 Beta**, 

[Open Source Code](https://github.com/MrFaiergmStudios/woodenspeed)

**The mod is in beta stage, so bugs may occur!**

**The mod and code are under an open license - GPL-3.0 license**

A guide on how to break a tree can be found in the "Gallery" tab!
